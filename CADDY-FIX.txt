Caddy / Pterodactyl fix

Symptom:
  /home/container/logs/error/proxy.err.log:
  sh: caddy: Operation not permitted

Cause:
  The upstream Caddy binary carries cap_net_bind_service=+ep.
  Pterodactyl Wings uses no-new-privileges and drops CAP_NET_BIND_SERVICE.

Fix:
  This Dockerfile recreates /usr/bin/caddy without the file capability.
  Plane listens on the high Pterodactyl allocation, so the capability is unnecessary.

New image tag:
  ghcr.io/reiniervg/pterodactyl-plane:v1.4.0-ptero2

Steps:
  1. Replace Dockerfile in GitHub with this version.
  2. Replace .github/workflows/build.yml with this version.
  3. Commit/push to main.
  4. Wait for the GitHub Action to finish successfully.
  5. In the existing Pterodactyl server, change Docker Image to:
       ghcr.io/reiniervg/pterodactyl-plane:v1.4.0-ptero2
  6. Restart the server.
