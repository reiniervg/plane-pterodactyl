PLANE PTERODACTYL - COMPLETE REPOSITORY

IMPORTANT:
The GitHub Actions workflow MUST be located exactly here:

    .github/workflows/build.yml

NOT:
    workflows/build.yml

Do not manually recreate the folder in GitHub's web editor.

RECOMMENDED UPLOAD METHOD
=========================

1. Extract this ZIP on your PC.
2. Open PowerShell inside the extracted 'plane-pterodactyl' folder.
3. Run:

   git init
   git branch -M main
   git add -A
   git commit -m "Install Plane True All-In-One ptero4"

4. If 'origin' does NOT exist yet:

   git remote add origin https://github.com/reiniervg/plane-pterodactyl.git

   If origin already exists, skip that command.

5. Because your GitHub repo already has commits, the cleanest method is normally:
   - clone the existing repo first,
   - delete/replace its working files with everything from this folder,
   - then run git add/commit/push.

   Example:

   git clone https://github.com/reiniervg/plane-pterodactyl.git
   cd plane-pterodactyl

   Copy ALL files from this package into that cloned folder, including the hidden .github folder.

   Then:

   git add -A
   git commit -m "Install Plane True All-In-One ptero4"
   git push origin main

6. On GitHub the repository root MUST show a '.github' folder.
   Open it and verify:
       .github/workflows/build.yml

7. GitHub -> Actions should then show:
       Build Plane True All-In-One Pterodactyl Image

8. The workflow publishes:
       ghcr.io/reiniervg/pterodactyl-plane:v1.4.0-ptero4

DO NOT upload only the visible files through GitHub's web page.
That is how '.github/workflows' can accidentally turn into a root 'workflows' folder.
